# بصير — نسخة الويب (أندرويد + آيفون)

موقع يشتغل كتطبيق: كاميرا مباشرة، يسمع «بصير، اوصفلي»، ويتكلم بالصوت.

## النشر المجاني (اختاري طريقة)

**GitHub Pages:** ارفعي محتوى هذا المجلد إلى مستودع عام، ثم Settings ← Pages ← Deploy from branch ← main / root.
الرابط يصير: `https://اسمك.github.io/اسم-المستودع/`

**Netlify Drop (من الكمبيوتر):** افتحي app.netlify.com/drop واسحبي هذا المجلد كامل. سجّلي حساب مجاني عشان يظل الرابط.

## على الجوال
1. افتحي الرابط في **Chrome** (أندرويد) أو **Safari** (آيفون).
2. أضيفيه للشاشة الرئيسية: أندرويد ← القائمة ⋮ ← «تثبيت التطبيق». آيفون ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
3. افتحيه، المسي الشاشة، واسمحي بالكاميرا والميكروفون والموقع.
4. قسم الأمان ← الإعدادات: الصقي مفتاح Anthropic واضغطي حفظ.

## الصوت واللغات
- **صوت الجوال (مجاني):** اختاري من أصوات جوالك، أو قولي «بصير، غيّر الصوت».
- **صوت طبيعي (ElevenLabs):** الأمان ← نوع الصوت ← «صوت طبيعي»، الصقي مفتاح ElevenLabs، واضغطي «حمّل الأصوات». نفس الصوت يتكلم كل اللغات.
  - عشان تلقين صوت يشبه اللي يعجبك: elevenlabs.io ← Voice Library، فلتري حسب اللغة والجنس واللهجة، واضغطي «Add to my voices»، وبعدها «حمّل الأصوات» في بصير.
- **اللغات:** أكثر من 20 لغة. أول مرة تختارين لغة جديدة، بصير يترجم الأزرار والكلام لها (يحتاج مفتاح Anthropic).

## التكلفة
- الاستضافة: مجانية.
- كل وصف: جزء صغير من السنت على مفتاح Anthropic (نموذج Haiku). خيار «أدق» يستخدم Opus وهو أغلى.
- صوت ElevenLabs: فيه خطة مجانية محدودة كل شهر، وبعدها مدفوع. صوت الجوال مجاني دائماً.

## متجر Google Play لاحقاً
افتحي pwabuilder.com، حطي رابط الموقع، واختاري Android، ويطلع لج ملف جاهز لـ Play Store. (حساب مطوّر Google: 25 دولار مرة وحدة.)
